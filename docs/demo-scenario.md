# Skenario Live Demo

## Persiapan

- Cek production deployment dan `/api/health`.
- Gunakan akun serta data demo khusus.
- Buka halaman utama sebelum screen sharing.
- Siapkan build lokal dan rekaman demo sebagai cadangan.

## Alur 3 Menit

1. Masalah dan pengguna sasaran, 20 detik.
2. Nilai pembeda, 20 detik.
3. Happy path fitur utama, 100 detik.
4. Metrik dampak dan keterkaitan SDG, 20 detik.
5. Keamanan, responsivitas, dan penutup, 20 detik.

## Fallback

Jika provider eksternal gagal, tampilkan cached response atau degraded mode yang jujur dan tetap dapat didemokan.
